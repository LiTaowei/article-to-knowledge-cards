# make-knowledge-cards

`make-knowledge-cards` 是一个用于生成复习知识卡片的 Skill。它可以把用户粘贴的文章，或本地 Markdown/TXT 文件，整理成结构统一、忠于原文的知识卡片。

## 1. 项目解决什么问题

阅读文章、课程笔记、章节摘录或文本资料后，用户通常还需要手动提炼重点、去重、整理成复习材料。这个项目解决的问题是：



* 从较长文本中提取真正重要的知识点，而不是简单摘抄原文。

* 把零散内容整理成便于复习的卡片。

* 保证一张卡片只讲一个知识点，避免多个概念混杂。

* 删除重复内容，保留原文中的条件、限定和结论。

* 避免生成原文没有的信息；原文知识点不足时，不强行凑卡片数量。

## 2. 主要功能



* 支持直接处理用户粘贴的文章正文。

* 支持读取本地 `.md` 和 `.txt` 文件。

* 通常输出 5～8 张知识卡片；如果原文独立知识点不足，会输出更少卡片并说明原因。

* 每张卡片固定包含：


  * 标题；

  * 核心知识；

  * 简明解释；

  * 例子或自测问题。

* 优先使用原文中的例子；原文没有例子时，使用自测问题，不虚构例子。

* 输出格式为 Markdown，便于复制、保存和继续编辑。

当前明确不支持：



* 网页抓取；

* PDF 处理；

* Anki 导出；

* 图形界面操作。

如果输入是网页链接或 PDF，需要先由用户提供粘贴文本，或将内容另存为 `.md`/`.txt` 文件。

## 3. 安装方法

该 Skill 不包含可执行脚本，也不需要安装运行时依赖。

### 方式一：在当前项目中使用

当前项目已经具备以下结构，可直接使用：



```
First\_skill/

├── README.md

└── skills/

&#x20;   └── make-knowledge-cards/

&#x20;       ├── SKILL.md

&#x20;       └── agents/

&#x20;           └── openai.yaml
```

### 方式二：复制到其他项目



1. 将整个 `skills/make-knowledge-cards/` 文件夹复制到目标项目的 `skills/` 目录下。

2. 保持以下相对路径不变：



```
skills/make-knowledge-cards/SKILL.md

skills/make-knowledge-cards/agents/openai.yaml
```



1. 在支持加载 Skill 的 Agent 环境中，通过 `$make-knowledge-cards` 调用。

无需执行 `pip install`、`npm install` 或其他构建命令。

## 4. 使用方法

### 4.1 处理粘贴文章

直接在对话中粘贴文章，并说明使用该 Skill：



```
使用 \$make-knowledge-cards，把下面这篇文章转换成知识卡片：

\[在这里粘贴文章正文]
```

### 4.2 处理本地 Markdown 文件



```
使用 \$make-knowledge-cards，把 ./notes/lesson.md 转换成知识卡片。
```

### 4.3 处理本地 TXT 文件



```
使用 \$make-knowledge-cards，读取 ./notes/lesson.txt 并生成知识卡片。
```

### 4.4 使用建议



* 如果希望保留章节结构，可优先提供 Markdown 文件。

* 如果文章较长，应提供完整文本，而不是只给标题或片段。

* 如果需要特定复习场景，可在请求中说明，例如 “偏考试复习”“多给自测问题”。

* 若原文知识点少于 5 个，输出会少于 5 张卡片，这是正常行为，用于避免凑数和编造。

## 5. 输入输出示例

### 输入示例



```
\# 费曼学习法

费曼学习法强调用自己的话解释概念。学习者可以先选择一个概念，然后假设自己正在教给初学者，用简单语言讲清楚。如果解释中出现卡壳或依赖专业术语，就回到材料重新学习，最后再整理和简化表达。

这个方法的重点不是背诵定义，而是发现自己理解中不清楚的部分。例如，学习“递归”时，如果只能说出“函数调用自己”，却不能解释终止条件，就说明理解还不完整。
```

### 输出示例



```
\# 知识卡片

\*\*来源主题：\*\* 费曼学习法通过向初学者解释概念来检验和完善理解。

\*\*卡片数量：\*\* 3

\*\*数量说明：\*\* 示例原文较短，只包含三个独立知识点，因此不强行凑满 5 张。

\## 卡片 1：费曼学习法的核心做法

\- \*\*核心知识：\*\* 费曼学习法要求学习者用自己的话，把概念讲给初学者听。

\- \*\*简明解释：\*\* 它关注能否用简单语言说明概念，而不是停留在复述定义或使用专业术语上。

\- \*\*例子或自测问题：\*\*

&#x20; \- 自测问题：如果只能背诵教材定义，能否说明已经掌握了这个概念？为什么？

\## 卡片 2：卡壳意味着需要回到材料

\- \*\*核心知识：\*\* 当解释卡壳或不得不依赖专业术语时，应重新学习相关材料。

\- \*\*简明解释：\*\* 卡壳位置暴露了理解不完整的部分。重新学习后，再继续解释并简化表达。

\- \*\*例子或自测问题：\*\*

&#x20; \- 自测问题：在讲解过程中出现卡壳时，费曼学习法建议如何处理？

\## 卡片 3：递归例子体现理解缺口

\- \*\*核心知识：\*\* 能说出“递归是函数调用自己”，但不能解释终止条件，说明对递归的理解仍不完整。

\- \*\*简明解释：\*\* 原文用递归说明，掌握概念不仅要知道表面定义，还要能解释关键组成部分。

\- \*\*例子或自测问题：\*\*

&#x20; \- 例子：学习“递归”时，只说“函数调用自己”，却没有说明终止条件。
```
